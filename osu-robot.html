Overview

An electromechanical robot that plays the rhythm game osu! by physically pressing keys on a Hall-effect keypad with solenoids. A PC reads the beatmap and sends timed key-press commands over serial to a Teensy 4.0, which fires the solenoids through MOSFET driver circuits.

How it works

  • Actuation: solenoids positioned over the keys of a Hall-effect keypad.
  • Driver circuits: logic-level MOSFETs switch each solenoid, with flyback diodes and a 12V power stage.
  • Firmware: Teensy 4.0 firmware in C++ (PlatformIO) receives commands and drives the solenoids with precise timing.
  • PC interface: a Python program using pySerial sends timed key-press commands to the Teensy.
  • Calibration: actuation latency is measured with a logic analyzer to correct timing and improve hit accuracy.
