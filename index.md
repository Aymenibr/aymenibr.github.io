## 🛠️ Troubleshooting Common Issues

### Problem: "Cannot connect to cluster"
**Solution:** Make sure your Kubernetes cluster is running and that you have a valid configuration file (usually called `kubeconfig`). st8ks looks for this file in the standard location. If you use a custom location, check the settings menu.

### Problem: "Application won't start"
**Solution:** Ensure your computer meets the minimum system requirements. Try restarting your computer and launching st8ks again. If problems persist, download the latest version from the website—updates often fix startup issues.

### Problem: "Dashboard looks empty"
**Solution:** Double-check that you're connected to the correct cluster. If you have multiple clusters, use the cluster selector at the top of the window to switch between them.
